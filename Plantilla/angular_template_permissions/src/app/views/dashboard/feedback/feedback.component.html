Feedback

It's recommended to have a section in the menu to allow the users to send feedback directly to the development Team - normally through email - , in order to receive information directly from them based on usage. Will help you to detect problems or receive improvements suggestions directly without intermediation, resulting on a better support service.

  • Send an email message to the group that gives the user support, can be done with just a link
  • Use a simple Form if you prefer
  • Try to answer them quickly
